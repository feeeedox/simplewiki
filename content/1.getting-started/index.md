# Welcome to SimpleWiki

**SimpleWiki** is a file-based documentation engine designed for the rapid creation and deployment of wiki systems. The software converts raw data in Markdown format into a classic, searchable, and high-performance documentation platform.

---

## Key Features

* **Optimized Loading Speed:** The engine is based on Nuxt 4 and the Nitro server, resulting in minimal load times.
* **File-based routing:** The directory structure of the source files automatically determines the resulting URL structure.
* **Tailwind CSS:** The visual design is implemented using modern utility-first CSS classes and is fully customizable.
* **MDC Support (Markdown Components):** Enables the direct embedding of Vue components within Markdown files.
* **Automated Table of Contents:** Each page automatically generates an interactive table of contents (TOC) for navigation.

## Technical Specifications

| Component | Technology | Purpose |
| :--- | :--- | :--- |
| Framework | Nuxt 4 | Application logic & SSR |
| Server Engine | Nitro | Server-side rendering & routing |
| Styling Framework | Tailwind CSS | Visual design |
| Data Format | Markdown / MDC | Content capture |
