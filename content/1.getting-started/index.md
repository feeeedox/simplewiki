# Welcome to SimpleWiki

**SimpleWiki** is a lightweight, file-based wiki built with **Nuxt Content**. It allows you to create clean, searchable documentation using Markdown while keeping your content in simple files.

Whether you're documenting a project, writing internal documentation, or publishing a public knowledge base, SimpleWiki focuses on simplicity, performance, and customization.

---

## Features

* File-based documentation powered by Markdown
* Support for MDC (Markdown Components)
* Automatic file-based routing
* Built-in full-text search
* Automatic table of contents
* Fully customizable with Tailwind CSS
* Fast server-side rendering with Nuxt 4

---

## Tech Stack

| Component      | Technology     |
| -------------- | -------------- |
| Framework      | Nuxt 4         |
| Content        | Nuxt Content   |
| Server         | Nitro          |
| Styling        | Tailwind CSS   |
| Content Format | Markdown + MDC |
